### ✨ Features
* 🛡️ **Anti-VPN & Alt Shield:** Real-time IP checks & auto alt-sweep.
* ⚖️ **Moderation Ladder:** 6-tier warning system, timeout, jail & unjail.
* 🎨 **Dynamic Cards:** Custom neon Canvas cards for `/aura`, `/iq`, `/besties`, and `/avatar`.
* 💬 **Emilia AI:** Chit-chat & memory powered by Llama 3.3 70B via Groq.
* 🎵 **Music System:** High-fidelity Lavalink audio streaming.
